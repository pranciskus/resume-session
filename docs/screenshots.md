# Reproduce the screenshots

Every documentation image uses fictional histories generated by `scripts/demo.mjs`. No screenshot reads the user's real history or credentials. The demo overrides the home directory, configuration path and history environment, checks that exactly five project sessions are discovered, and cancels the picker without selecting a chat.

The picker is a real PTY capture. The account list and launch plans come from the actual CLI. Handoff paths and the recovery manifest come from a real `--prepare` run against the fake Claude history. The alias image shows a launch-plan excerpt with the long handoff prompt omitted. The recovery image is a formatted manifest summary, not a claim that the CLI has a team dashboard. Temporary paths and generated handoff UUIDs are shortened for readability.

Images are plain terminal windows rendered in xterm.js using Playwright, with any explanatory notes inside the terminal as comments. They contain no AI-generated interface text. The generation tools are optional and do not ship in the npm package.

On macOS or Linux, with Python 3 and Node.js 22.17+:

```sh
npm ci --ignore-scripts
npm install --prefix /tmp/resume-release-tools --ignore-scripts playwright@1.64.1 @xterm/xterm@6.0.0
/tmp/resume-release-tools/node_modules/.bin/playwright install chromium
node scripts/demo.mjs /tmp/resume-release-tools
```

The script writes five PNG files to `docs/images/` and deletes its temporary fictional histories. It never launches a model or spends model credits. The PTY capture helper is Unix-specific; the CLI itself is tested on Windows too.
